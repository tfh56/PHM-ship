# PHM-ship

本软件是一套面向船艇全生命周期运维的零代码提示命令系统，以船艇发动机一次轮询采集的 839 测点样本为数据基线，通过自然语言提示命令驱动 Elasticsearch、Kibana、Elastic Agent、Fleet、llama.cpp 等开源组件，实现从环境部署、数据湖构建、本地推理、人机界面到标签重构的全生命周期闭环。用户无需编写任何代码，只需通过提示命令即可完成全部业务流程。
